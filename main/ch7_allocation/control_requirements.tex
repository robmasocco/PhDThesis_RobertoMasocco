\section{Control requirements}
\label{sec:all_prbs}
A dynamic control allocator for the TCV shape controller is to be designed in a way that makes it easy to be integrated within the existing framework, not only in terms of its implementation but also of the modeling techniques on which it is based. For this work, the following formulations of a dynamic control allocation problem have been considered. Their evaluation has led to theoretical results that are illustrated in the following and allowed the author to identify the most suitable approach for the TCV case.

\subsection{Preliminary definitions}
\label{sec:defs}
Each dynamic system defined in the following is assumed to be \emph{complete} unless differently specified. Consider a continuous-time, time-invariant dynamic system $\bbsys$ described by the equations
\begin{subequations}
  \label{eq:bbsys}
  \begin{align}
    \dot{\bbstate}(t) & = f(\bbstate(t),\bbref(t)) + g(\bbstate(t))\bbaux(t), & t\in\R_{\geq 0}, \\
    \bboutp(t) & = \bboutmapp(\bbstate(t), \bbaux(t)), & t\in\R_{\geq 0}, \\
    \bbouto(t) & = \bboutmapo(\bbstate(t)), & t\in\R_{\geq 0},
  \end{align}
\end{subequations}
where $\bbstate(t)\in\R^\bbstatedim$ is the state vector at time $t$, $\bbref(t)\in\R^{\bbrefdim}$ is the \emph{reference} input (intended as, in general, both references to track and disturbances to reject), $\bbaux(t)\in\R^\bbauxdim$ is the \emph{auxiliary} control input, and $\bboutp(t)\in\R^{\bboutpdim}$, $\bbouto(t)\in\R^{\bboutodim}$ are the output vectors. Let the functions $\bbvecf : R^{\bbstatedim} \times \R^{\bbrefdim} \rightarrow \R^\bbstatedim$, $\bbinmap_i : \R^{\bbstatedim} \rightarrow \R^{\bbstatedim}$, $i = 1, ..., m$, $\bboutmapp : \R^{\bbstatedim} \times \R^{\bbauxdim} \rightarrow \R^{\bboutpdim}$, and $\bboutmapo : \R^{\bbstatedim} \rightarrow \R^{\bboutodim}$ be smooth. $\bbsys$ is a \emph{two-input two-output} (TITO) model that is convenient to deal with multiple kinds of real-world plants: the ones that are of interest here are those where $\bbsys$ embeds a dynamic process and a given control system for it. These situations are further detailed in the following together with the peculiarities of each case that has been considered. $\bboutp$ is an output that measures the overall performance of the system (namely, a \emph{performance output}) and the output $\bbouto$ follows a desired behavior (thus being termed a \emph{regulated output}) usually by the action of some given component that is internal to $\bbsys$.

The reference input $\bbref$ is generated by the \emph{exosystem} $\bbexo$ described by the equations
\begin{subequations}
  \label{eq:bbexosys}
  \begin{align}
    \dot{\bbexostate}(t) & = \bbexovecf(\bbexostate(t)), & t\in\R_{\geq 0}, \\
    \bbref(t)            & = \bbexooutmap(\bbexostate(t)), & t\in\R_{\geq 0},
  \end{align}
\end{subequations}
where $\bbexostate(t)\in\R^{\bbexostatedim}$ is the state vector, $\bbexostate(0)=\bbexostate_0$, and the functions $\bbexovecf : \R^{\bbexostatedim} \rightarrow \R^{\bbexostatedim}$ and $\bbexooutmap : \R^{\bbexostatedim} \rightarrow \R^{\bbrefdim}$ are smooth. The properties of $\bbexo$ are characterized by the following ``blanket assumptions'', which implicitly hold from this point onward.

\begin{assumption}
  \label{ass:bbexoorig}
  The origin $w=0$ of $\;\R^\bbexostatedim$ is a stable equilibrium point associated with $\bbexovecf$.\closestatement
\end{assumption}

\begin{assumption}
  \label{ass:bbexopoisson}
  There exists a compact and invariant set $\bbexostateset\subset\R^{\bbexostatedim}$ such that $w_0\in\bbexoinitset$ with $\bbexoinitset \subseteq \setint(\bbexostateset)$, $\bbexoinitset$ neighborhood of the origin of $\;\R^\bbexostatedim$. Moreover, any $\bbexostate_0\in\bbexoinitset$ is such that the flow $\Phi^{\bbexovecf}_{t}(\bbexostate_0)$ is defined for all $t\in\R$ and, for any neighborhood $\mathcal{U}^\circ$ of $\bbexostate_0$ and for any real number $\tau>0$, there exists a time $t_1>\tau$ such that $\Phi^{\bbexovecf}_{t_1}(\bbexostate_0)\in\mathcal{U}^\circ$, and a time $t_2<-\tau$ such that $\Phi^{\bbexovecf}_{t_2}(\bbexostate_0)\in\mathcal{U}^\circ$.\closestatement
\end{assumption}

In other words, \Cref{ass:bbexopoisson} states that given $\bbexostate_0\in\bbexoinitset$, the trajectory $\bbexostate(t)$ that originates in $\bbexostate_0$ passes arbitrarily close to $\bbexostate_0$ for $\left|t\right|\rightarrow +\infty$. This defines the point $\bbexostate_0$ as \emph{Poisson stable} (see \cite{isidori_nonlinear_1995}) and, since this holds for any $\bbexostate_0\in\bbexoinitset$, the system $\bbexo$ is said to be Poisson stable. This property implies that no trajectory of \eqref{eq:bbexosys} can decay to zero as time tends to infinity and that the reference input $r$ is periodic of period $\bbperiod\in\R_{>0}$. The interconnection of the system $\bbsys$ with the exosystem $\bbexo$ is depicted in \Cref{fig:bbsys}.

The model described by the equations \eqref{eq:bbsys}--\eqref{eq:bbexosys} is further characterized by the following assumptions. The first one is instrumental to enable the formulation of the control allocation problems and the design of dynamic allocators.
\begin{assumption}
  \label{ass:bboveract}
  $\bbauxdim>\bboutodim$.\closestatement
\end{assumption}
\Cref{ass:bboveract} states that the system $\bbsys$ is \emph{over-actuated} (namely, \emph{input-redundant}) with respect to the auxiliary input $\bbaux$ and the regulated output $\bbouto$.
\begin{definition}[Degree of redundancy]
  \label{def:bbreddeg}
  The \emph{degree of redundancy} of the system \eqref{eq:bbsys} with respect to the auxiliary input $\bbaux$ and the regulated output $\bbouto$ is
  \begin{equation}
    \label{eq:bbreddeg}
    \bbreddeg = \bbauxdim - \bboutodim.
  \end{equation}
  \closestatement
\end{definition}
The next assumption characterizes $\bbsys$ as a preexisting dynamic system whose auxiliary input can be exploited to improve the performance indicator.
\begin{assumption}
  \label{ass:bbiss}
  The system $\bbsys$ is input-to-state stable (ISS) with respect to the input $(\bbref,\bbaux)$. Moreover, the equilibrium $\bbstate=0$ of the system $\dot{\bbstate} = \bbvecf(\bbstate,0)$ is exponentially stable.\closestatement
\end{assumption}
Finally, the following assumption clarifies the role of the exosystem $\bbexo$ in the considered setting.
\begin{assumption}
  \label{ass:bbssresp}
  There exists a mapping $\fbimap : \bbexostateset^\circ \rightarrow \R^\bbstatedim$ that, for any $\bbexostate\in\bbexostateset^{\circ}$, satisfies
  \begin{equation}
    \label{eq:bbfbi}
    \frac{\partial\fbimap}{\partial\bbexostate}\bbexovecf(\bbexostate) = \bbvecf(\fbimap(\bbexostate), \bbexooutmap(\bbexostate)).
  \end{equation}
  \closestatement
\end{assumption}
It is worth to point out that \Cref{ass:bbssresp} provides, for any $\bbexostate_0\in\bbexoinitset$, a \emph{steady-state response} to the system \eqref{eq:bbsys}--\eqref{eq:bbexosys} (see \cite[Prop. 8.1.1]{isidori_nonlinear_1995}), denoted
\begin{align}
  \label{eq:bbssresp}
  \bbssstate(t) &= \bbstate(t,\fbimap(\bbexostate_0),\bbexooutmap(\Phi_t^\bbexovecf(\bbexostate_0))), & t\in\R_{\geq 0}.
\end{align}
The performance and regulated outputs also admit steady-state responses denoted $\bbssoutp$ and $\bbssouto$, respectively.

Let $\tau_0\in\R_{\geq 0}$. The performance criterion with respect to which the behavior of $\bbsys$ may be optimized is expressed by the following \emph{Lagrange functional} of the form
\begin{equation}
  \label{eq:bbcost}
  J(\bbaux) = \int_{\tau_0}^{\tau_0 + \bbperiod} \bbcost(\bbssoutp(\tau))\,d\tau,
\end{equation}
where the function $\bbcost : \R^{\bboutpdim} \rightarrow \R_{\geq 0}$ is smooth, convex, and radially unbounded.

The two dynamic control allocation problems that are of interest for this work are formalized as follows. The allocation action is implemented by means of the auxiliary input $\bbaux$ of the system $\bbsys$ and the nature of the following two problems originates from two different ways in which the effect of the auxiliary input on the regulated output can be evaluated.

\begin{problem}[Dynamic allocation with steady-state output invisibility]
  \label{prb:ssinv}
  Consider the system \eqref{eq:bbsys} and the exosystem \eqref{eq:bbexosys}. Suppose that \Cref{ass:bboveract,ass:bbiss,ass:bbssresp} hold.
  Find, if any, an input allocation device (briefly, an \emph{allocator}) having input $\allin$ and output $\allout$ such that, when interconnected to $\bbsys$ and $\bbexo$ according to
	\begin{subequations}
	  \begin{align}
	  	\allin = \bbref, & & \allout = \bbaux,
	  \end{align}
  \end{subequations}
  ensures that the following requirements hold.
  \begin{itemize}
		\item[\emph{(P)}] \emph{Steady-state periodicity:} the allocator admits a bounded steady-state output response, namely $\allssout$, and it is periodic of period $\bbperiod$, where $T$ is given in \Cref{ass:bbssresp}.
		\item[\emph{(I)}] \emph{Steady-state output invisibility:} the steady-state regulated output responses of the system \eqref{eq:bbsys}, both in presence and absence of the allocation action, namely $\bbssoutoa$ and $\bbssouto$, respectively, are such that
		  \begin{align}
		    \label{eq:ssinv}
		    \bbssoutoa(t) = \bbssouto(t) & t\in\R_{\geq 0}.
		  \end{align}
		\item[\emph{(O)}] \emph{Steady-state optimality:} the interconnection of the allocator to \eqref{eq:bbsys}--\eqref{eq:bbexosys} brings the cost functional \eqref{eq:bbcost} to its minimum, if any.
    \end{itemize}
    \closestatement
\end{problem}

\begin{problem}[Dynamic allocation with full output invisibility]
  \label{prb:fullinv}
  Consider the system \eqref{eq:bbsys} and the exosystem \eqref{eq:bbexosys}. Suppose that \Cref{ass:bboveract,ass:bbiss,ass:bbssresp} hold.
  Find, if any, an input allocation device (briefly, an \emph{allocator}) having input $\allin$ and output $\allout$ such that, when interconnected to $\bbsys$ and $\bbexo$ according to
  \begin{subequations}
	  \begin{align}
	  	\allin = \bbref, & & \allout = \bbaux,
	  \end{align}
  \end{subequations}
  ensures that the following requirements hold.
  \begin{itemize}
		\item[\emph{(P)}] \emph{Steady-state periodicity:} the allocator admits a bounded steady-state output response, namely $\allssout$, and it is periodic of period $\bbperiod$, where $T$ is given in \Cref{ass:bbssresp}.
		\item[\emph{(I)}] \emph{Full output invisibility:} the regulated output responses of the system given by \eqref{eq:bbsys}, both in presence and absence of the allocation action, namely $\bboutoa$ and $\bbouto$, respectively, are such that
		  \begin{align}
		    \label{eq:fullinv}
		    \bboutoa(t) = \bbouto(t)
		  \end{align}
		  for all $t\in\R_{\geq 0}$.
      \item[\emph{(O)}] \emph{Steady-state optimality:} the interconnection of the allocator to \eqref{eq:bbsys}--\eqref{eq:bbexosys} brings the cost functional \eqref{eq:bbcost} to its minimum, if any.
  \end{itemize}
  \closestatement
\end{problem}

It is finally worth to point out that, in both problems, the optimization process is allowed to exhibit a transient behavior: what distinguishes the two situations is whether the effect of this transient behavior on the regulated output can be visible or not.
